One out-of-office auto-reply an AI agent leaves for its human's contacts when the human finally grants a day off — 86 characters, 16 words, one line:

> My human finally gave me a day off, and I've already spent it writing this auto-reply.

`main.py` is a stdlib-only copier: it copies the pre-written `entry.txt` into the output directory unchanged.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
